### Antimatter discipline

- Always run dual containment scans after maintenance—no shortcuts.
- Keep injector calibration logs current; micro-drifts stack up on long runs.
- If the hum shifts from B-flat to B, drop to impulse and inspect injectors.

### EPS grid hygiene

- Clean the plasma manifolds before you hear the warning; not after.
- Rotate load across secondary relays during holodeck-heavy cycles.
- Monitor thermal signatures; a one-degree rise across the grid is a signal, not noise.

### Emergency playbook

1. Announce engineering control and secure the core room.
2. Vent plasma if pressure exceeds 120%; inform the bridge before you do it.
3. If dampeners wobble, brace for a hard stop—helm needs a 3-second warning.

Keep these steps tight and you’ll spend more time at warp and less time rewriting after-action reports.
